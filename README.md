# Print Agent v1 (Legacy)

This branch preserves the sanitized history of the original Print Agent v1.

V1 is no longer the maintained product. It is kept for project history,
migration reference, and review of the original Node-based print server.

Current development lives on the `main` branch of this repository, which
contains Print Agent v2: the maintained desktop app and installer.

Local runtime files, credentials, ngrok URLs, logs, and build outputs are
intentionally excluded from this branch.
